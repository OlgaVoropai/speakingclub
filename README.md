# Speaking Club online

Статичний лендінг для online speaking club (група 6-8 учасників, Zoom, рівень B1+).
Повне ТЗ: `docs/TZ.md`.

## Розробка та збірка

- Установка залежностей: `npm install`
- Запуск лінтерів: `npm run lint`
- Форматування коду: `npm run format`
- Збірка проєкту: `npm run build`
