# ТЗ: лендінг «Speaking Club online»

Версія 1.0 · для розробки в OpenCode · 22 жовтня 2026

## 1. Загальні відомості

| Параметр | Значення |
| --- | --- |
| Назва | Speaking Club online |
| Слоган | Speaking Club, на якому ти вчишся говорити англійською вільно і впевнено! |
| Мета сайту | Залучення учасників у клуб. Головна дія (CTA): «Приєднатися зараз» (перехід у Telegram) |
| Цільова аудиторія | Дорослі, рівень англійської B1 і вище |
| Мова сайту | Українська (`lang="uk"`) |
| Терміни | Старт негайно, жорсткого дедлайну немає |

## 2. Вихідні дані про клуб

| Параметр | Значення |
| --- | --- |
| Формат | Група 6-8 учасників (максимум 10) |
| Тривалість заняття | 90 хвилин |
| Платформа | Zoom |
| Рівні | B1 і вище. Рівні A1-A2 та підліткові групи не передбачені |
| Розклад | Субота або неділя, час за домовленістю (часовий пояс Europe/Kyiv) |
| Ведуча | Ольга Воропай, 10+ років викладання, фото є |
| Тарифи | 300 грн за 1 заняття; 1200 грн за 4 заняття |
| Перевірка рівня | Коротка безкоштовна бесіда в Telegram (5-10 хвилин) перед першою зустріччю, щоб підтвердити рівень |
| Запис на заняття | Через повідомлення «КЛУБ» у Telegram: https://t.me/Olga_Boxy |

**Правило для розробника:** не вигадувати факти, яких немає в цьому ТЗ (відгуки, статистику, сертифікати, імена, досягнення). Якщо даних бракує, ставити помітний placeholder `TODO` і повідомляти про це у звіті.

| Хостинг статики | GitHub Pages, репозиторій `speakingclub` |
